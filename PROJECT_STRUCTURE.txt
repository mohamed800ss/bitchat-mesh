Key Features:
=============

1. Mesh Networking:
   - Uses Google Nearby Connections API (P2P_CLUSTER strategy)
   - Supports up to 100-200 meter range
   - Automatic multi-hop message relay

2. Encryption:
   - AES-256 CBC mode encryption
   - All messages encrypted before transmission
   - Shared secret key (can be exchanged via QR code in production)

3. Permissions Handling:
   - Android 12+ Bluetooth permissions (BLUETOOTH_SCAN, BLUETOOTH_ADVERTISE, BLUETOOTH_CONNECT)
   - Android 13+ Wi-Fi permissions (NEARBY_WIFI_DEVICES)
   - Location permissions for Nearby Connections API

4. UI/UX:
   - Material Design compatible
   - Simple device discovery interface
   - Real-time chat with message timestamps
   - Connection status indicator

5. Multi-Hop Routing:
   - Message deduplication using message IDs
   - Automatic relay to connected nodes
   - Hop count tracking
