# BitChat Mesh

**تطبيق مراسلة محلي بدون إنترنت** باستخدام تقنية Mesh Networking + تشفير AES-256.

## الميزات
- اتصال P2P بدون إنترنت (Bluetooth + Wi-Fi Direct عبر Google Nearby Connections)
- تشفير AES-256 لكل الرسائل
- دعم Multi-Hop (نقل الرسائل عبر أجهزة وسيطة)
- واجهة بسيطة

## التثبيت
انظر إلى `QUICK_START.md` و `COMPLETE_DOCUMENTATION.md`

## التقنيات
- Android (Java)
- Google Play Services Nearby Connections API
- Gson
- AES-256 Encryption
